# Triage Labels

技能使用五个规范的 triage 角色进行通信。此文件将这些角色映射到本仓库 issue tracker 中使用的实际 label 字符串。

| mattpocock/skills 中的角色 | 我们 tracker 中的 Label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 完全指定，准备好给离线代理 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会被处理 |

当技能提到一个角色时（例如「应用 AFK-ready triage label」），使用此表中对应的 label 字符串。

编辑右列以匹配你实际使用的词汇。
